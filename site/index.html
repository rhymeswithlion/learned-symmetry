Label-free tests of learned symmetry

Is your vision model secretly cheating?

A network can score well on its test set and still know nothing about an object once it is rotated. The test set never shows it, because the test set has the same holes as the training data.

1 · A published detector

Trained with mirror images. Never shown upside down.

We asked a widely distributed object detector about 400 validation objects, each shown four ways. A normal test set holds only the first two views, so it cannot show the gap.

Now take the labels away.

The invariance defect compares the class scores of an image with their average over a set of flips. It is 0 when the scores are the same at every flip in the set and grows toward 1 as they differ, and it needs no labels.

Each circle is one set of flips. The mirror's defect is the smallest, yet it is still times the defect of shifting the image by a single pixel, so this detector is not mirror-invariant either. Nothing in its accuracy shows that.

Then train it with all four flips.

Fine-tuning with every flip and a consistency penalty lowers the vertical flip's defect, and accuracy under that flip rises with it. Section 8 in the paper →

2 · The test, hands on

Drag the scores. Watch where invariance breaks.

Three objects, each at four flips, scored on three classes fill a table of twelve rows and three columns. The test centres it, averages each object's scores over the views a set of flips joins, and measures what the averaging took away: 0 when the flips change nothing, 1 when nothing survives them.

Swipe the tables sideways for steps ② to ⑤.

Drag up or down. Dragging a view's label adds the same number to every class in that row, which ② removes; dragging a class's name adds it to the whole column, which ③ removes. Hover a number to see the values ④ averages it with.

Click a circle to take the defect over that set of flips.

3 · Every subgroup at once

A larger set of symmetries never has a smaller defect.

A set of transformations that is closed under composing and undoing them is a group, and a group inside another is its subgroup. A Hasse diagram draws every subgroup as a circle, the smaller ones lower, with a line from each subgroup up to the next larger ones that contain it.

The diagram below shows the ten subgroups of the eight symmetries of a square: four rotations and four flips. The four flips of the sections above are one of the circles in its third row.

The defect is monotone with respect to inclusion. For subgroups H and K of the group G:

H ≤ K ≤ G  ⟹  δ(H) ≤ δ(K)

with equality exactly when RHf is already K-invariant. Theorem 1 (iii), Section 3 →

Along any line going up, the defect stays level or grows, so the lowest circles above zero name the symmetries that failed.

4 · What cheating looks like

A memorizer's defect has a closed form.

The simplest classifier that is right at every pose it saw, and knows nothing of the rest, keeps one scale per pose. Trained with weight decay it ends with the same scale on every seen pose and zero on every hole.

5 · When it costs accuracy

Where the best possible answer is known, the cheat has a price.

On synthetic renders of rotated shapes, the best rule for the training data and the best rule for deployment can both be computed. Hollow dots are accuracy on inputs like the training data; filled dots, over the full circle.

The plain network is within a hair of the best rule for its training data, and that rule is itself a cheat: it is the right answer to the wrong question. The share of inputs whose predicted class a rotation changes bounds how much accuracy is lost, and it too needs no labels. Section 6 in the paper →
